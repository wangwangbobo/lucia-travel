侧载安装 · 大约 3 分钟
  1. 1在 Mac 或 Windows 上装好 Sideloadly，用数据线连上 iPhone。
  2. 2把下载的 ipa 拖进 Sideloadly，填入自己的 Apple ID，点 Start 重新签名。
  3. 3手机打开 设置 → 通用 → VPN 与设备管理，信任证书，回桌面打开 RoamChina。
免费 Apple ID 的签名 7 天有效，到期重签一次即可；付费开发者账号能签一年。不想用侧载工具的话，也可以拿 Xcode 直接编译到手机。
