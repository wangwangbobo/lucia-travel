# Lucia · 出行，不必慌张

AI 旅行助手 Lucia 的 iOS 高保真原型静态预览。

**在线预览：** https://wangwangbobo.github.io/lucia-travel/

## 这里有什么

- 12 个界面：行程首页、计划路线、社区、翻译、我的、行前清单、AI 助手、地点详情、笔记海报、发布帖子、调整顺序、离线语句库
- 可切换的界面导览，支持键盘 ← →
- 一套从十张参考图收敛出来的设计系统：奶油纸底、墨线描边、硬阴影、荧光色块、贴纸与等宽小字
- 全部截图为 iOS 模拟器实拍

## 说明

- 原 App 使用 SwiftUI 构建（iOS 18+），交互原型运行在 iOS 模拟器中。
- 本仓库只托管静态网页预览，GitHub Pages 无法运行原生 iOS 应用。
- 地图、票务、社区内容均为本地演示数据，不连接真实服务。
- 网页为单文件 HTML/CSS/JS，无构建依赖。

## 本地查看

```bash
python3 -m http.server 8765
# 打开 http://localhost:8765/
```
